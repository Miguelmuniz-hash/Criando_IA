# TechBot IA - Assistente Inteligente Local

Projeto de Chatbot desenvolvido em Python com interface gráfica moderna, sistema de autenticação de utilizador, alternância de temas (claro/escuro) e respostas estruturadas por módulos de conhecimento local.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**
- **Tkinter**: Biblioteca gráfica nativa do Python.
- **ttkbootstrap**: Framework para estilização e temas da interface.

---
